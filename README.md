# Lot 7 Cafe

Editorial website for Lot 7 Cafe, a specialty coffee bar and vinyl listening room in Naga City, Camarines Sur. Live at <https://lot7.cafe>.

Built with SvelteKit (Svelte 5) and prerendered to static HTML with `@sveltejs/adapter-static`.

## Developing

Requires Node `^20.19.0 || >=22.12.0`.

```sh
npm install
npm run dev       # dev server
npm run check     # type-check + Svelte diagnostics
npm run build     # production build into build/
npm run preview   # serve the production build locally
```

| Hero intro (the video frame opens out of frosted glass, then the tagline and pills) | `src/lib/components/Hero.svelte`, "INTRO: THE FROSTED REVEAL" block: timings, keyframes, reduced-motion opt-out; `src/app.html` holds it while the page loads in a background tab and skips it for 12 hours after it plays (if you edit that script, update its CSP hash in `vite.config.ts`) |

### Images

Photos are rendered with `<enhanced:img>` from [`@sveltejs/enhanced-img`](https://svelte.dev/docs/kit/images). At build time each one becomes AVIF, WebP and JPEG in several sizes with a `srcset`, so add new photos as high-quality originals in `src/lib/assets/images/` and reference them by path:

```svelte
<enhanced:img src="$lib/assets/images/photo.jpg" alt="…" sizes="(min-width: 1200px) 526px, 92vw" loading="lazy" />
```

The photo masters, brand artwork, link-preview image and favicons are exported from the official files in `design-assets/` by `python -I scripts/export-assets.py` (needs Pillow). The raw camera files in `design-assets/PICTURES/` are about 400 MB and are not committed: keep them in the shared drive and copy them in before re-running the script. To swap a photo, change its entry in `PHOTOS` and re-run.

Each photo also has a tiny blurred preview that shows while it downloads. After adding or swapping a photo, run `python -I scripts/generate-placeholders.py` (needs Pillow) to refresh `src/lib/placeholders.ts`, and pass the file name to the card as `placeholder="photo"`.

Inside a photo card, wrap it in `<MediaFrame aspect="16 / 10" tags={['LEFT', 'RIGHT']}>` for the hover zoom, light sweep and caption pill.

### Hero video

`lot7-showcase-av1.mp4` (AV1, preferred) and `lot7-showcase.mp4` (H.264 fallback) must contain the same footage. To re-encode from a new master:

```sh
ffmpeg -i master.mp4 -an -c:v libx264 -crf 23 -preset slow -movflags +faststart static/videos/lot7-showcase.mp4
ffmpeg -i master.mp4 -an -c:v libsvtav1 -preset 6 -crf 38 -g 240 -movflags +faststart static/videos/lot7-showcase-av1.mp4
```

If the AV1 profile or level changes, update the `codecs` string on its `<source>` in `src/lib/components/Hero.svelte` (`ffprobe -show_entries stream=profile,level`).

## Deployment

Deployed on Vercel as a static site; `vercel.json` sets the build output (`build/`), clean URLs and the HTTP security headers. The Content-Security-Policy itself is generated by SvelteKit (`csp` in `vite.config.ts`) so its script hashes always match the build.
